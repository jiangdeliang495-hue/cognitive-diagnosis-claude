# DINA 认知诊断算法说明

实现：`src/dina.py`（纯标准库，零第三方依赖）。数值契约见设计规格 §6。

## 1. 模型

- 潜在变量：每名学生 α_i ∈ {0,1}^K，共 **2^K = 32** 种画像（K=5）；bit k 表示掌握 KP_{k+1}
  （bit0 ↔ KP1）。
- 理想作答（And 门，非补偿）：η_ij = ∏_k α_{ik}^{q_jk}，即须掌握题目 Q 行要求的**全部**
  知识点才算会。
- 观测模型：P(X_ij=1 | α_i, g_j, s_j) = (1−s_j)^{η_ij} · g_j^{1−η_ij}。

## 2. 参数与先验

- 画像先验**固定均匀** π(α) = 1/2^K（K=5 时 1/32），**不拟合类比例**。
- guess / slip ∈ **[0.02, 0.35]**（恒有 guess + slip < 1）；初始 g=0.2、s=0.1。

## 3. EM 迭代（对数域稳定）

- **E 步（logsumexp）**：log p_ic = log π_c + Σ_j [X_ij·log p_cj + (1−X_ij)·log(1−p_cj)]，
  其中 p_cj = (1−s_j)^{η_cj} · g_j^{1−η_cj}；对每名学生按 logsumexp 归一化得 p_ic。
- **M 步（期望计数 + 精确区间截断）**：
  - s_j = N_j^10 / (N_j^11 + N_j^10)，N_j^10 = Σ_i Σ_c p_ic η_cj (1−X_ij)，N_j^11 = Σ_i Σ_c p_ic η_cj X_ij。
  - g_j = N_j^01 / (N_j^01 + N_j^00)，N_j^01 = Σ_i Σ_c p_ic (1−η_cj) X_ij，N_j^00 = Σ_i Σ_c p_ic (1−η_cj)(1−X_ij)。
  - 更新后**精确截断到 [0.02, 0.35]**；有效分母为 0 时**保留旧值**。

## 4. 停止准则与似然

- `max_iter = 200`，`tol = 1e-8`。
- 每轮对数似然 log L = Σ_i logsumexp_c( log π_c + Σ_j log P(X_ij|α_c) )。
- 两步判断：先拒绝**显著负增量**（delta < −1e-9 → `ArithmeticError`，EM 对数似然应单调不减），
  再以 delta < tol 判 **converged**；`max_iter` 耗尽 → `converged=False`（不冒充收敛）。
- 一致性：最终题参、`loglik_history` 末项、用最终题参重算的似然一致（允许 ~1e-9 浮点误差）。

## 5. 掌握概率（对数后验边际）

E 步在**对数域归一化**得到画像后验 p_ic（`log p_ic` 经 logsumexp 归一化后取指数）；
边际 P(掌握 KP_k | X_i) = Σ_{c: bit_k=1} p_ic 直接对**已归一化的画像后验概率**求和，
`_marginalize` 不再执行 logsumexp。输出顺序 KP1..KP5。这是**掌握概率**，与答对率严格区分，
也不由合成真值 `profile_id` 生成。

## 6. 与经典 IRT 的关系

DINA 是**离散潜在类**诊断模型：潜在空间是有限画像，题参是 guess/slip，作答映射到「每个技能
掌握与否」。经典 IRT（如 2PL）是**连续潜在特质**模型：θ 为标量，题目用难度/区分度的 logistic
特征曲线。二者都通过题参刻画题目，但 DINA 给**逐技能**诊断、IRT 给**单维能力**。DINA 的 And 门
非补偿：未掌握题目所需全部技能（η=0）时答对概率降为 guess；只有全部掌握（η=1）时答错概率才是 slip。
这是「答对率 ≠ 掌握概率」的根源。

## 7. 数据与局限

- 合成小样本：12 人 × 24 题，后验边际方差大，掌握概率是估计而非确定判定。
- 画像单调强假设只约束**造数**（合成真值沿 DAG 下闭），不裁剪模型推断（模型仍允许 32 画像）。
- 固定均匀先验 1/2^K：先验向均匀收缩，短题列（观测信息少）的后验更接近先验；
  不强断言极端后验必然保守（取决于观测证据强度）。
- guess/slip 硬区间 [0.02, 0.35]：小样本正则化，可能低估极端题参。
- 作答噪声为独立 Bernoulli，无真实学生异质性、无缺失；恢复精度不外推真实课堂。

## 8. 实际验证

算法内核 `tests/test_dina.py` 22 项 unittest 全部通过，含：

- K=1 单题手算：答对后验 9/11、答错 1/9；多技能 And 门；边际概率而非 MAP 画像。
- 画像位序与 Q 列对齐；后验归一化；800 题长列对数稳定性。
- 非法 Q/X/形状拒绝；不修改输入；确定性；题/技能置换不变性。
- 一步 EM 手算 fixture：K=1、Q=[[1]]、X=[[1],[1],[1],[0]]，g=(3·2/11)/(3·2/11+8/9)=27/71→截断 0.35，
  s=(1/9)/(3·9/11+1/9)=11/254；一步后似然严格提高。
- 似然单调不降、题参边界、`max_iter` 耗尽不冒充收敛、固定均匀先验、最终题参/后验/似然一致性。

后端数据链（`tests/test_seed.py` / `tests/test_api.py`）另验证：从 SQLite 读回 Q/X 重跑真 EM 逐题
比对落库 guess/slip 与 60 条 diagnosis、X 完整 288 条、API 数值与库逐格一致。

演示库实测（`docs/validation/demo-em-report.txt`）：EM 在 **33 轮内收敛**（`converged=True`），
对数似然由初始 −165.27 单调升至 −135.91；最终题参与重算似然一致。
核心阶段 Python unittest **79 项**外部验收通过（`docs/validation/python-external-final.txt`）；加入建议功能后的完整后端 **147/147** 通过（`docs/validation/advice-backend-external-final.txt`），保留全部核心回归。

## 9. LLM 建议与诊断算法的职责

`src/advice.py`不估计能力。它只读取当前合成学生已存的DINA概率、独立答对率、知识点与前置边，构造中文诊断快照；只在用户点击时调用DeepSeek V4 Pro最高思考，请其给出1–3项学习重点、原因、具体行动和检查方法。服务关闭只读DB连接后才联网，不读取profile_id或其他学生，不重跑EM、不写库、不改变图表概率。

输出必须符合固定JSON结构：知识点ID存在且互异、文本非空并有长度限制，未知字段剥离，截断或无效内容拒绝。前端以textContent显示；结构校验不能证明建议在教学上正确，仍需人工判断。6组建议区模拟E2E已通过，真实付费生成尚待运行时配置，不能拿mock成功证明模型质量。
