# PRD —— 智能化认知诊断 MVP

## 1. 背景与意图

算法实习作业：用 **DINA（Deterministic Inputs, Noisy "And" gate）认知诊断模型**，
从学生的题目作答中估计「每名学生 × 每个知识点」的**掌握概率**，并用一个极简中文
Web 界面把它讲清楚。核心是**演示一个真实的诊断算法**（不是把答对率当掌握度），
同时把模型口径、局限讲明白。

- 输入：Q 矩阵（题目 ↔ 知识点）、X 作答矩阵（学生 ↔ 题目）。
- 输出：每名学生每个知识点的掌握概率（连续值 ∈ [0,1]）。
- 展示：切换学生 → 雷达图、掌握概率表、前置知识图谱。

## 2. 目标（Goals）

- G1：SQLite 存储 Q 矩阵与 X 作答矩阵，DINA 从这二者估计掌握概率。
- G2：5 个知识点（分数概念、通分、分数加减、分数乘除、应用题），≥20 题，≥10 名学生
  （取 24 题、12 名学生）。
- G3：简单有向无环前置知识图谱，用于**解释学习顺序**。
- G4：DINA 用 32 种掌握画像、对数域稳定的后验边际、EM 题参校准；**不把答对率当掌握概率**。
- G5：极简中文 Web 界面，可切换学生，展示雷达图、概率表、知识图谱；清晰、可访问、适配手机，
  图表全部由真实诊断数据生成。
- G6：可复现（固定随机种子）合成数据，**明确演示局限**。
- G7：零第三方运行依赖（Python 标准库 + SQLite + 原生 HTML/CSS/JS）。
- G8：可选 LLM 根据当前诊断快照生成具体行动建议，显式点击才联网付费，不改变诊断概率。

## 3. 非目标（Non-Goals）

- 不做真实学生数据采集、不做多轮自适应测试。
- 不做用户认证、多用户、持久会话、部署上线。
- 不引入第三方运行时库、构建链、CDN。

## 4. 反目标（Anti-Goals，若发生即算失败）

- **A1**：把「答对率 / 总分」冒充「掌握概率」。
- **A2**：用知识图谱偷偷改变潜在空间或估计结果（图谱只做解释）。
- **A3**：伪造测试、Prompt、Git 历史、插件使用或人工参与记录。
- **A4**：未经授权推送、发邮件或使用付费资源。用户已授权公开 GitHub 交付与显式模型建议；邮件仍仅为草稿。
- **A5**：伪造模型来源或读取既有凭据、旧剪贴板、密钥链。允许用户主动通过服务端环境或 getpass 提供运行时 Key；不读取 Claude 的 Key，不将兼容别名当作 Anthropic 身份证明。

## 6. 非功能需求

- NFR-1 零运行依赖：`python3` 标准库 + SQLite + 原生前端，无 CDN/npm。
- NFR-2 可复现：固定种子与确定性画像指派，重复运行得到相同数据与结果。
- NFR-3 可读性：源码中文注释、算法说明与代码一一对应。
- NFR-4 数值稳定：画像后验在对数域用 log-sum-exp 归一化，边际对归一化的画像后验求和。

## 9. 局限说明（须在 README 与前端明示）

- **合成小样本**：12 人 × 24 题，后验边际方差大；掌握概率是估计而非确定判定。
- **画像单调强假设**：合成真值全部沿 DAG 单调（前置未掌握则后继必未掌握）；真实数据
  未必满足。此假设只约束**造数**，不裁剪模型推断（模型仍允许 32 画像）。
- **固定均匀先验 1/2^K（K=5 时 1/32）**：短题列（观测信息少）的后验更接近先验，不强断言极端后验
  必然保守；不拟合类比例。
- **guess/slip 硬区间 [0.02, 0.35]**：小样本正则化，可能低估极端题参。
- **噪声结构简单**：作答为独立 Bernoulli，无真实学生的猜测/粗心异质性、无缺失值；
  恢复精度不能外推到真实课堂。
