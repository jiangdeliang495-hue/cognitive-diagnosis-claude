## 6. 算法设计（DINA）—— 已锁定的可测试数值契约

### 6.1 模型

- 潜在变量：每名学生 α_i ∈ {0,1}^K，共 **2^K = 32** 种画像（演示默认 K=5）；
  位 k 表示掌握 KP_{k+1}（bit0 ↔ KP1）。
- 理想作答（And 门，非补偿）：η_ij = ∏_k α_{ik}^{q_jk}（须掌握 Q 行**全部**知识点才算会）。
- 观测模型：P(X_ij=1 | α_i, g_j, s_j) = (1−s_j)^{η_ij} · g_j^{1−η_ij}。

### 6.2 参数与先验（锁定）

- 画像先验 **固定均匀 π(α) = 1/2^K**（本演示 K=5 时为 1/32），**不拟合类比例**。
- guess / slip 区间：**g_j, s_j ∈ [0.02, 0.35]**（恒有 g_j + s_j < 1）；初始 g=0.2、s=0.1。
- DDL `CHECK` 同步该边界与正向性，**禁止 0/1 端点**。

### 6.3 EM 迭代（锁定）

- **E 步（对数域 logsumexp）**：对每名学生，
  log p_{ic} = log π(α_c) + Σ_j [X_ij log p_cj + (1−X_ij) log(1−p_cj)]，
  其中 p_cj = (1−s_j)^{η_cj} g_j^{1−η_cj}；按学生 logsumexp 归一化得到 p_{ic}。
- **M 步（期望计数 + 精确区间截断）**：
  - N_j^10 = Σ_i Σ_c p_{ic} η_cj (1−X_ij)；N_j^11 = Σ_i Σ_c p_{ic} η_cj X_ij；
    s_j = N_j^10 / (N_j^11 + N_j^10)。
  - N_j^01 = Σ_i Σ_c p_{ic} (1−η_cj) X_ij；N_j^00 = Σ_i Σ_c p_{ic} (1−η_cj)(1−X_ij)；
    g_j = N_j^01 / (N_j^01 + N_j^00)。
  - 更新后**精确截断到 [0.02, 0.35]**；**有效分母为 0 时保留旧值**。

### 6.4 停止准则与似然（锁定）

- `max_iter = 200`，`tol = 1e-8`。
- 每轮计算对数似然 log L = Σ_i logsumexp_c( log π_c + Σ_j log P(X_ij | α_c) )。
- **收敛判断（两步：先拒绝异常，再判收敛）**：
  1. 先拒绝异常：若 `loglik[t] − loglik[t−1]` 为**显著负值**（超出浮点容差，如 < −1e-9），
     判为非单调异常而非收敛（EM 对数似然应单调不减）。
  2. 再判收敛：增量非负且 `loglik[t] − loglik[t−1] < tol` 时判为 **converged**。
- **`max_iter` 耗尽 ≠ 收敛**：达到 200 轮仍未满足上述准则时，返回 `converged=False`（not_converged）。
- **一致性**：最终返回的题参、`loglik_history` 末项、以及用最终题参重算的似然一致
  （允许 ~1e-9 浮点误差）；`loglik_history = [init, iter_1, …, iter_T]`，
  其中 `init` 为初始题参下的似然，`iter_T` 为最终题参下的似然（历史含初始与最终）。

### 6.5 掌握概率（对数后验边际）

P(掌握 KP_k | X_i) = Σ_{c: α_{c,k}=1} p_{ic}，全部对数域 log-sum-exp 后取指数。
输出数组顺序 = KP1..KP5。这是「掌握概率」，与答对率严格区分，也不由真值生成。

### 6.6 接口签名与真值隔离（锁定）

```python
fit(Q, X, *, prior="uniform", guess_bounds=(0.02, 0.35), slip_bounds=(0.02, 0.35),
    init=(0.2, 0.1), max_iter=200, tol=1e-8) -> FitResult
```

- `FitResult` 含：`guess`、`slip`、`loglik_history`、`posterior_marginal`、`converged`。
- `fit` **只接 Q、X 与显式数值配置，绝不读取 `profile_id`**。
- 内核支持任意 K；**较小 K（如 K=1、2）用于确定性手算测试**，演示默认 K=5。

### 6.7 与经典 IRT 的关系

DINA 是**离散潜在类**诊断模型：潜在空间是有限画像，题参是 guess/slip，把作答映射到
「每个技能的掌握与否」。经典 IRT（如 2PL）是**连续潜在特质**模型：潜在 θ 为标量，
题目用难度/区分度的 logistic 特征曲线。二者都通过题参刻画题目行为，但 DINA 给出
**逐技能**诊断，IRT 给出**单维能力**；DINA 的 And 门是非补偿的：未掌握题目所需的**全部**
技能（η=0）时，答对概率降为 guess（答错概率 1−guess）；只有全部掌握（η=1）时，答错概率
才是 slip。这是它与总分/单维 IRT 的关键差异，也是「答对率 ≠ 掌握概率」的根源。

### 6.8 合成与验证

- 固定种子生成 g_j、s_j（区间内，多知识点题 guess 更小），据此抽样 X；EM 从 X **恢复**
  题参与画像后验。
- E2E 对照：估计掌握概率 vs 已知真值 profile_id，量化恢复精度并**明示局限**。

## 7. 索引约定（锁定）

- Q 是「题目 × 知识点」，X 是「学生 × 题目」；题与知识点使用**稳定 ID 排序**。
- **bit0 ↔ KP1**；掌握概率数组、Q 行向量、画像位掩码一律按 KP1..KP5 顺序对齐。
- Q 长表**缺省为 0**；**禁止空知识需求题**（每道题 ≥1 项 required=1）。
- 合成真值 `profile_id` 只用于生成与验证；API 不暴露。

## 11. 合成小样本限制

- 12 人 × 24 题，小样本：后验边际方差大，掌握概率是估计而非确定判定。
- 画像单调强假设只约束造数，不裁剪模型推断；真实数据未必单调。
- 固定均匀先验 1/2^K（K=5 时 1/32）：向先验收缩，极端后验偏保守；不拟合类比例。
- guess/slip 硬区间 [0.02, 0.35]：小样本正则化，可能低估极端题参。
- 作答噪声为独立 Bernoulli：无真实学生异质性、无缺失值；恢复精度不外推真实课堂。
